# Mattel_-_HyperScan

Thumbnails for Mattel HyperScan software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`), named after the MAME short names, as the MAME `hyperscan` software list has them.

The snaps were taken with the MAME libretro core in RetroArch: each disc (CHD) is run on its own for 3600 frames (7200 for the ones that were still on a logo) and the last frame is kept, at 640x480. Without a player the games stay on their intro or title menu, which is what the snaps show.
